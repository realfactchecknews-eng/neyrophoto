# Нейрофото

Статический сайт (GitHub Pages) для neyrofoto.ru: конструктор аватарок, нейро-генерация, проверка фото на следы ИИ, банк аватарок, тарифы и рекламные места.

## Структура
- `index.html`, `create.html`, `check.html`, `bank.html`, `pricing.html`
- `js/config.js` — единая настройка: лимиты, провайдер генерации, реклама (РСЯ), оплата (Telegram Stars, Lava Top), тарифы
- `js/avatar.js` — генератор SVG-аватарок; `js/detect.js` — анализ метаданных изображения

## Локальный запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## Бэкенд
Папка `worker/`: Cloudflare Worker + D1 + R2. Деплой и настройка: `worker/README.md`. Пока `apiBase` в `js/config.js` пуст, сайт работает автономно (лимиты в браузере, без оплаты и загрузок в банк).

## Что пока заглушка
- Lava Top: вебхук только сохраняет платежи (нужен пример тела вебхука).
- Серверный детектор и генерация зависят от внешних сервисов, их надо проверить на живых данных.
- Реквизиты в `js/config.js` (раздел `legal`) нужно заполнить; юридические тексты стоит показать юристу.
